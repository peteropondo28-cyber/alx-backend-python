*Unit Tests for `access_nested_map`

## Overview

This project contains unit tests for the `access_nested_map` function. The tests are designed to verify the correct behavior of the function when accessing nested dictionaries using various paths.

## Files

*   `test_access_nested_map.py`: Contains the unit tests for the `access_nested_map` function.

## Prerequisites

*   Python 3.x
*   `unittest` module (built-in)
*   `parameterized` library (install using `pip install parameterized`)

## Running the Tests

To run the tests, navigate to the directory containing the `test_access_nested_map.py` file and execute the following command in your terminal:

```bash
python -m unittest test_access_nested_map.py
